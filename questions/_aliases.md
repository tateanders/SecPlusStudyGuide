# Typed-answer aliases

Each line lists terms that count as the same answer when you type them.
If any term on a line is an accepted answer, every term on that line is accepted.
Matching ignores case, spaces, hyphens and punctuation, so you don't need spelling variants of those.
Aliases match whole answers only ("MFA" = "multifactor authentication", but "MFA token" is not rewritten).
